# LockedIn Labs

We build healthcare systems and the engineering practices that make consequential operations work. Our portfolio spans broker and member experiences, contact center operations, workforce readiness, governed AI, and model evaluation.

## Open source

Start with the source, architecture, and verification guidance for our public projects.

| Project | What it does | Explore |
| --- | --- | --- |
| **Agent Console** | Local-first observability for Claude Code and Codex: sessions, agents, token usage, cache activity, and estimated costs. | [Source and setup](https://github.com/LockedinLabs-AI/agent-console) · [Architecture](https://github.com/LockedinLabs-AI/agent-console/blob/main/docs/ARCHITECTURE.md) · [Published downloads](https://github.com/LockedinLabs-AI/agent-console/releases/latest) |

Each project documents its own installation options, license, security boundary, and release status. Source changes and published downloads can be at different versions; use the project's release notes and verification instructions for the artifact you install.

For a technical review, start with **Agent Console**. Its [measurement definitions](https://github.com/LockedinLabs-AI/agent-console/blob/main/docs/MEASUREMENTS.md), [security policy](https://github.com/LockedinLabs-AI/agent-console/blob/main/SECURITY.md), and [contribution guide](https://github.com/LockedinLabs-AI/agent-console/blob/main/CONTRIBUTING.md) explain what the product measures and how to evaluate or improve it.

## Contribute and follow

Our public work also includes [MOEModels](https://github.com/LockedinLabs-AI/moemodels), a model discovery and deployment-fit project. Follow each repository for its actual releases and current scope.

Start with a reproducible issue, a documentation improvement, or a focused pull request. You do not need organization membership to contribute to a public repository. If a project is useful to you, star its repository to help others discover it, or watch releases to follow updates.
