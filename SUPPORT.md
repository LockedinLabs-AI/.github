# Support

| Need | Where to go |
| --- | --- |
| Reproducible product bug or feature proposal | The affected repository's issues and contribution guide. |
| Incorrect organization profile or community document | [This repository's issues](https://github.com/LockedinLabs-AI/.github/issues). |
| Suspected vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue. |
| Private product review, partnership, or commercial support | [LockedIn Labs contact](https://lockedinlabs.ai/contact/). |
| Conduct or privacy concern | Request a private channel through the company contact page. |

Include the project and version, expected and actual behavior, minimal reproduction, and relevant environment details. Remove tokens, personal paths, customer records, and other private content from logs and screenshots before sharing.

Support for public projects is provided through their maintainers and published policies. Response times and service commitments apply only where explicitly agreed. For an upstream project mirrored here, use the canonical support location named in its README.
